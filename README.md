## Proyectos

### 🔗 Criptomoneda desde cero
Proyecto personal para entender Bitcoin a nivel de código. Voy por fases: fundamentos criptográficos → cadena de bloques → minería (Proof of Work) → transacciones y modelo UTXO → red P2P → y al final leer Bitcoin Core directamente.

`Criptografía` `Estructuras de datos` `Redes P2P`

### 📚 Sistema de registro de estudiantes
Aplicación full-stack con Node.js, Express y MongoDB. Proyecto final de Desarrollo Web: CRUD completo, manejo de rutas, persistencia y vistas.

`Node.js` `Express` `MongoDB`

### 🖼️ Comparación de imágenes por similitud coseno
Implementación en Python que representa imágenes como vectores y mide qué tan parecidas son usando similitud coseno. Salió de un proyecto de Álgebra Lineal, con documentación formal incluida.

`Python` `Álgebra lineal` `Procesamiento de imágenes`

### 💅 Pretty Nails, Lu — Ingeniería de Requerimientos

`Análisis de requerimientos` `UML` `IEEE 830`
